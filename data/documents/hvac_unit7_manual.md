# HVAC Unit-7 Maintenance Manual

## Equipment Description
HVAC Unit-7 serves the east wing. Components include supply fan, return fan, cooling coil, and variable frequency drive (VFD).

## Predictive Maintenance Sensors
Unit-7 is monitored via:
- Supply air temperature
- Fan motor current (amps)
- VFD fault codes
- Filter differential pressure

## Filter Replacement
Replace filters when differential pressure exceeds 1.2 inches w.c. (water column).
Typical interval: 90 days under normal occupancy.
Delayed filter replacement increases fan motor load and reduces cooling efficiency.

## Motor Current Guidelines
Normal range: 12–18 A under design load.
Warning: sustained current above 20 A — inspect filters, belts, and coil fouling.
Critical: current above 24 A or repeated VFD overcurrent trips — schedule immediate service.

## Cooling Performance
Supply air temperature should be 13–16°C below return air temperature when cooling mode is active.
If delta-T drops below 8°C for more than 48 hours, inspect refrigerant charge and coil cleanliness.

## Seasonal Service Schedule
- Spring: coil cleaning, belt tension check, refrigerant leak test
- Fall: heating section inspection, economizer calibration
- Monthly: filter check, condensate drain verification

## Decision Support Rules
Schedule preventive maintenance within 2 weeks if:
- Filter DP above 1.0 in. w.c. for 5+ days
- Motor current trending upward (>5% week-over-week) without load change
- Any VFD fault code F001 (overtemperature) in the last 30 days

## Parts
- Filter set: FILT-U7-MERV13
- Drive belt: BELT-U7-B58
- Contact facilities for refrigerant work — certified technician required.
